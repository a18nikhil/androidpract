TextWatcher Application

1. Aim

To create an Android application that responds to text input using TextWatcher with EditText, without requiring the user to press a button.

2. Background Information

TextWatcher is used to detect changes in text entered in an EditText in an Android application. In this practical, EditText is used to enter text, and TextView displays a message when the entered text contains the letter "A" or "a". The onTextChanged() method detects text changes automatically without requiring a button. Kotlin is used to handle the text changes and display the message.

3. Steps / Procedure

    Open Android Studio, click New Project, select Empty Views Activity, and click Next.

  2. Enter Project Details

    Set the project name to keypressapp, package name to com.example.keypressapp, language to Kotlin, and minimum SDK to API 24. Click Finish.
