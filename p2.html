Simple Calculator Application

1. Aim

To create a calculator app that performs addition, subtraction, division and multiplication operation on numbers.

2. Background Information

A calculator is an application used to perform basic mathematical operations. In this practical, EditText is used to enter two numbers, Buttons are used to select the mathematical operation, and TextView is used to display the result. Kotlin is used to perform the calculations and handle invalid inputs, such as division by zero.

3. Steps / Procedure

  1. Create a New Project

    Open Android Studio, click New Project, select Empty Views Activity, and click Next.

  2. Enter Project Details

    Use these settings:

    • Name: calculator
    • Package Name: com.example.calculator
    • Language: Kotlin
    • Minimum SDK: API 24

    Click Finish and wait for the project to load.

  3. Write the XML Code

    Open app → res → layout → activity_main.xml. Select Code view, delete the existing code, and paste the XML code given below.

  4. Write the Kotlin Code

    Open app → kotlin+java → com.example.calculator → MainActivity.kt. Replace its code with the Kotlin code given below.

  5. Run the Application

    Select an Android emulator or connected phone and click Run (▶). Wait for the calculator to open.

  6. Test the Calculator

    Enter two numbers and tap Addition, Subtraction, Multiplication, or Division. The result appears below the buttons. Also try dividing by zero to check the error message.
