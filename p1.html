PRACTICAL 01

Hello World Application

1. Aim

To create "hello world" application to display "hello world" in the middle of the screen in the emulator as well as android phone.

2. Background Information

Android Studio is software used to develop Android applications. XML (Extensible Markup Language) is used to design the screen, while Kotlin is used to write the program. In this practical, TextView is used to display the message "Hello World", and LinearLayout is used to place the text in the center of the screen. The application can be tested on both an Android emulator and a real Android phone.

3. Steps / Procedure

  1. Create a New Project

    Open Android Studio and click New Project. Select Empty Views Activity and click Next.

  2. Enter Project Details

    Enter the following details:

    • Name: helloworld
    • Package Name: com.example.helloworld
    • Language: Kotlin
    • Minimum SDK: API 24

    Click Finish and wait for the project to load.

  3. Write the XML Code

    Go to app → res → layout → activity_main.xml.

    Open Code view, delete the existing code, and paste the given XML code.

  4. Write the Kotlin Code

    Go to app → kotlin+java → com.example.helloworld → MainActivity.kt.

    Delete the existing code and paste the given Kotlin code.

  5. Run the Application

    Select an Android emulator from the device list and click the Run (▶) button.

    Wait for the application to open.

  6. Check the Output

    The application will display Hello World in the center of the screen.
