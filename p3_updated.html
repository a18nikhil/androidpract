PRACTICAL 03

Spinner Application with Images

1. Aim

To create a spinner application with strings taken from resource directory res/values/strings.xml and on changing the spinner value, image will change. Image is saved in the drawable directory.

2. Background Information

A Spinner is an Android component used to select an item from a dropdown list. In this practical, the list items are stored in the strings.xml file, and images are stored in the drawable directory. When the user selects an item from the Spinner, the ImageView displays the corresponding image. Kotlin is used to handle the selection and change the image.

3. Steps / Procedure

  1. Create a New Project

    Open Android Studio, click New Project, choose Empty Views Activity, and click Next.

  2. Enter Project Details

    Use these settings:

    • Name: spinnerapp
    • Package Name: com.example.spinnerapp
    • Language: Kotlin
    • Minimum SDK: API 24

    Click Finish and wait for the project to load.

  3. Write the Layout Code

    Open app → res → layout → activity_main.xml. Select Code view and replace the existing code with the given XML layout.

  4. Add the Fruit Names

    Open app → res → values → strings.xml. Replace its contents with the given strings.xml code to add Apple, Banana, and Mango to the list.

  5. Add the Fruit Images

    Open app → res → drawable and copy three image files into this folder: apple.png, banana.png, and mango.png. Use exactly these lowercase filenames.

  6. Write the Kotlin Code

    Open app → kotlin+java → com.example.spinnerapp → MainActivity.kt. Replace the existing code with the given Kotlin code.

  7. Run and Test the Application

    Select an emulator or connected Android phone and click Run (▶). Open the dropdown and select a fruit. Its image should appear below the list.
